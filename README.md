# 小说分段助手（novel-segmenter）

> 一个 WorkBuddy / CodeBuddy Skill：网络小说正文自动分段 + 错别字与标点校对 + 标题提炼。
> 把「一逗到底」的长段落，改造成网文读者习惯的短段节奏，同时把错别字和标点问题挑出来。

## 这是什么

你只要在对话框里**贴一段中文小说 / 网文正文**（什么话都不用说），它就会：

1. **自动分段**：按句末标点切分，一句一段为主，对话独立成段，控制单段 8–28 字。
2. **标点升级**：把该断句却偷懒用了逗号的地方改成句号。
3. **错别字纠正**：同音 / 形近错字（的地得、在再、做作、他她它、需须、账帐……）。
4. **标题提炼**：自动总结一个不超过 10 字的小说完章标题（网文常见 / 轻小说 / 章回体 / 国外 四选一）。

并产出三份固定交付物：

| 文件 | 用途 |
|---|---|
| `分段正文.txt` | **纯净正文，无序号标记**，直接全选复制粘贴进起点「作家助手」 |
| `校对报告.html` | 带段号对照视图，改动处黄底高亮，悬停显示原文 |
| `修改清单.csv` | Excel 可直接打开，逐条列出「第几段第几句、改了什么、为什么改」 |

## 三种使用方式

- **方式 A（最推荐）**：直接粘贴正文，什么都不用说，技能自动处理。
- **方式 B（网页版，秒出）**：双击打开 `网页版.html`，粘贴正文点「开始分段」，纯本地跑，不联网不上传；
  右侧「绳匠终端」还能接 DeepSeek / 智谱 GLM / Kimi 等大模型做语义校对。
- **方式 C（脚本）**：跑 `scripts/fenduan.py` 批量处理，只用 Python 标准库，无需装依赖。

## 网页版亮点

- 绝区零风格 UI、日夜切换、加载动画、翻译按钮。
- 开关齐全：标题风格、段落节奏滑块、补全引号、半角转全角、纠常错字。
- 可填 API Key 启用 AI 语义校对（同一份正文先由大模型返修订稿，再走本地引擎分段高亮出清单）。

## 如何安装（作为 Skill）

把本文件夹整体复制到你的 skill 目录：

- 用户级：`C:\Users\<你的用户名>\.workbuddy\skills\`
- 项目级：`<你的工作目录>\.workbuddy\skills\`

## 文件结构

```
novel-segmenter/
├── SKILL.md                  # 完整工作流、分段规则、标点升级规则、纠错边界
├── 安装说明.md               # 安装与三种用法说明
├── 网页版.html               # 纯本地网页版（双击即用）
├── scripts/
│   └── fenduan.py            # 分段引擎（Python 标准库）
└── references/
    ├── 错别字表.md           # 网文高频错别字对照
    └── 分段细则.md           # 边界情况处理（对话夹叙述、省略号、破折号、数字与英文）
```
