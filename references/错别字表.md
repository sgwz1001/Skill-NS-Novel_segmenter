# 网文高频错别字对照表

只在**明确判定为错误**时才改。拿不准的写进「待确认」，让作者自己定。

## 一、结构助词（出错率最高）

| 正确用法 | 判断口诀 | 常见错例 |
|---|---|---|
| 的 | 后面接名词：美丽**的**风景 | 美丽地风景 ✗ |
| 地 | 后面接动词：飞快**地**跑 | 飞快的跑 ✗ |
| 得 | 前面是动词，后面是补语：跑**得**快 | 跑的快 ✗ |

高频错例：狠狠的砸下去 → 狠狠**地**砸下去；气的发抖 → 气**得**发抖；不由的 → 不由**得**。

## 二、同音混淆

| 正 | 误 | 辨析 |
|---|---|---|
| 再 | 在 | 「再说一遍」表重复；「在说话」表进行 |
| 做 | 作 | 具体动作用「做」（做饭）；抽象搭配用「作」（作出决定、作为） |
| 须 | 需 | 「必须」表必要；「需要」表需求 |
| 账 | 帐 | 钱财相关一律「账」（账户、算账）；布幔才是「帐」（帐篷） |
| 竟 | 竞 | 「竟然、毕竟」；「竞争、竞技」 |
| 辨 | 辩 | 分辨用「辨」；辩解用「辩」 |
| 已 | 以 | 「已经」表完成；「以为、可以」 |
| 即 | 既 | 「立即、即将」；「既然、既是」 |
| 采 | 彩 | 「神采、风采」；「色彩、彩虹」 |
| 泄 | 泻 | 「发泄、泄露」；「腹泻、倾泻」 |
| 度 | 渡 | 时间用「度过」；水面用「渡过」 |
| 象 | 像 | 「好像、image 类比」用「像」；「现象、印象」用「象」 |

## 三、形近字

蘖/孽、暴/爆（暴露 / 爆发）、渺/缈（渺小 / 缥缈）、慕/幕（羡慕 / 帷幕）、
籍/藉（书籍 / 慰藉）、燥/躁（干燥 / 急躁）、栗/粟（战栗 / 粟米）、
盘/磐（盘子 / 磐石）、嘴/咀（嘴巴 / 咀嚼）。

## 四、网文场景高频词

| 正确 | 常见误写 |
|---|---|
| 一鼓作气 | 一股作气 |
| 迫不及待 | 迫不急待 |
| 甘拜下风 | 甘败下风 |
| 川流不息 | 穿流不息 |
| 蛛丝马迹 | 蛛丝蚂迹 |
| 走投无路 | 走头无路 |
| 变本加厉 | 变本加利 |
| 声名鹊起 | 声名雀起 |
| 屹立不倒 | 耸立不倒（语境错，非错字） |
| 寒暄 | 寒喧 |
| 部署 | 布署 |
| 报仇雪恨 | 报仇血恨 |
| 天翻地覆 | 天翻地复 |

## 五、人称代词

他 / 她 / 它 / 祂 —— 前后必须一致。同一角色在同一章里性别代词跳变，
**先标记再问作者**，不要自作主张统一（可能是伪装、易容、灵魂互换等设定）。

## 六、坚决不改的内容

- **方言与口语**：「咋整」「得亏」「搁哪儿呢」
- **刻意重复**：「快，快，再快一点！」
- **网文黑话与生造词**：金手指、扮猪吃虎、灵气复苏、氪金、装逼
- **人物口癖**：结巴、语气词、外号
- **专有名词**：人名、地名、功法、招式、门派

## 七、只标记不改

1. **专有名词不一致**——例如前文「周明博」后文「周云博」，很可能是笔误，
   但也可能是同族兄弟。列进清单让作者确认。
2. **疑似漏字**——句子读不通但补法不唯一。
3. **逻辑矛盾**——上一句说是白天，下一句写月光。
4. **数字前后不符**——「三个人」下一句变成「四人齐声道」。
