# 分段细则 · 边界情况处理

主规则见 SKILL.md，这里只收录容易踩坑的具体情形。

## 一、为什么要拆

传统出版物一段几百字很正常，但网文读者绝大多数在手机上读。
一屏大约容纳 200 字，一段超过三行，视觉上就形成"墙"，读者划走的概率显著上升。
所以网文的段落不是语法单位，而是**呼吸节奏单位**——一句一段是常态，不是错误。

## 二、对话处理

### 基本原则
对话独立成段，不与叙述混排。

原文：
> 他冷笑一声，"你以为你赢了？"，然后转身就走。

处理：
> 他冷笑一声。
>
> "你以为你赢了？"
>
> 然后转身就走。

### 说话人标签
「XX 道」「XX 说」紧跟在引号后的，**跟对话同段**：

> "我不同意。"周明博摇了摇头。

这是一个完整的表达单元，不拆。但如果标签后又接了新动作、新描写，就断开：

> "我不同意。"周明博摇了摇头。
>
> 他站起身，走到窗前。

### 长对话
单段对话超过 60 字时，按对话内部的句号拆分成多段，全部保留在引号内的处理方式：
首段以 `“` 开头不加 `”`，末段以 `”` 收尾——这是出版规范。
**但网文实践中更常见的是每段都完整闭合引号**。默认采用后者，用户提出要求再切换。

## 三、标点专项

### 省略号
`……` 是两个字符，视为一个整体的句末标点。
`。。。` `...` `···` 一律规范化为 `……`。
省略号后不再加句号。

### 破折号
`——` 表示解释或转折延续，**不作为分段点**。破折号前后属于同一段。

### 感叹号与问号
天然的句末标点，直接分段。
`？！` 连用视为一个整体，不在中间断开。

### 引号嵌套
外层 `“”`，内层 `‘’`。分段只看最外层闭合状态，内层引号不影响判断。

### 书名号、括号
`《》` `（）` 内部的标点不参与分段判断，视为一个原子块。

## 四、不该拆的情况

以下结构中的逗号**不能**升级成句号：

| 类型 | 例子 |
|---|---|
| 并列成分 | 桌上摆着刀，剑，枪三样兵器 |
| 状语前置 | 在那个下着雨的夜晚，他离开了 |
| 紧密转折 | 不是不想，是不敢 |
| 条件复句 | 只要他还活着，这事就没完 |
| 递进关系 | 不仅输了钱，还搭上了命 |
| 主语共享 | 他抬起头，看了看天，又低下了头（同一主语连续动作，可拆但需谨慎，节奏优先时才拆） |

「主语共享」这一条是灰色地带：网文里通常**会拆**，因为节奏更重要。
默认拆分，但每段至少保证语义完整。

## 五、该拆的信号

看到这些，逗号基本都该升级为句号：

- 逗号后跟：于是 / 然后 / 接着 / 随后 / 紧接着 / 但是 / 可是 / 不过 / 所以 / 因此
- 逗号前后主语不同：`周明博点了点头，赵瑞龙却皱起了眉`
- 逗号前后是"动作 + 心理"的切换：`他推开门，心里咯噔一下`
- 逗号前后是"外景 + 人物"的切换：`风停了，他睁开眼睛`

## 六、数字与英文

- 阿拉伯数字、英文单词内部绝不断开
- 「3.5 米」「Level 9」中的符号不是句末标点
- 中文数字与量词之间不断开

## 七、特殊排版元素

以下内容**整块保留，不参与分段**：

- 系统提示框：`【叮！恭喜宿主获得……】`
- 章节标题行
- 分隔线：`***` `———` `※※※`
- 诗词、歌词、书信正文（保持作者原有换行）
- 属性面板、状态栏这类罗列式内容

## 八、段落数量的合理区间

以 1000 字正文为例：

| 段数 | 判断 |
|---|---|
| < 20 段 | 太密，读者会累 |
| 25 ～ 50 段 | 舒适区，主流网文的实际节奏 |
| > 70 段 | 过碎，情绪被切断，长句缓冲不足 |

如果分完发现落在区间外，调 `--合并上限` 参数，而不是改判断规则。
